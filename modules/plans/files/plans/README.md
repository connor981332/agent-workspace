# Plans

Cross-project plans. This index is the source of truth for every plan's status.

Each plan is one file, `plans/<slug>.md`. Its first `## Status` block has these fields: `**State:**`, `**Updated:**` (YYYY-MM-DD), `**Branches / MRs:**`, `**Done:**`, `**In progress:**` and `**Next step:**`, so a reader with no session memory can resume from it. State is one of `DRAFT`, `PLANNED`, `PARTIALLY IMPLEMENTED`, `FULLY IMPLEMENTED` or `FULLY VERIFIED`, and the row below must agree with it. `aw check-docs` checks this.
